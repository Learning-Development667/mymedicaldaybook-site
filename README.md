# My Medical Daybook: the website

The public site for My Medical Daybook (Daybook), at mymedicaldaybook.co.uk. Plain HTML, CSS and JavaScript, no build step, served by GitHub Pages from `main`.

The app itself lives in its own repository, `Learning-Development667/Mark_Medical`, and runs at app.mymedicaldaybook.co.uk.
